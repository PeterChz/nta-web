# NTA – Página web (Tulcán)

Sitio web estático (HTML + CSS) publicado con GitHub Pages.

- **Ver la página:** https://peterchz.github.io/nta-web/
- **Editar en el navegador:** abre este repositorio en github.com y pulsa la tecla `.`

## Archivos
- `index.html` – Inicio (portada, resumen de servicios).
- `nosotros.html` – Historia, ficha de la empresa, misión, visión y valores.
- `servicios.html` – Servicios y proceso de trabajo.
- `cobertura.html` – Mapa de rutas Colombia – Ecuador – Perú.
- `contacto.html` – Datos de contacto, formulario (abre WhatsApp) y mapa.
- `styles.css` – diseño compartido. Colores (rojo, negro, blanco) al inicio, en `:root`.
- `script.js` – menú móvil, animaciones y formulario.
