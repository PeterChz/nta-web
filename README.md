# NTA – Página web (Tulcán)

Sitio web estático (HTML + CSS) publicado con GitHub Pages.

- **Ver la página:** https://peterchz.github.io/nta-web/
- **Editar en el navegador:** abre este repositorio en github.com y pulsa la tecla `.`

## Archivos
- `index.html` – contenido de la página (busca los textos entre `[corchetes]` y los comentarios `COMPLETAR`).
- `styles.css` – diseño. Los colores de la marca están al inicio, en `:root`.

## Rutina de trabajo en VS Code
1. **Pull** al empezar (bajar lo último).
2. Editar.
3. **Commit** + **Push** al terminar (subir a GitHub). La página se actualiza en 1–2 minutos.
