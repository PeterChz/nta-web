# NTA – Página web (Tulcán)

Sitio web estático (HTML + CSS + JS) publicado con GitHub Pages.

- **Ver la página:** https://peterchz.github.io/nta-web/
- **Editar en el navegador:** abre este repositorio en github.com y pulsa la tecla `.`

## Estructura de carpetas

```
nta-web/
├── index.html          Inicio (portada, servicios, certificaciones)
├── nosotros.html       Trayectoria, ficha de empresa, misión, visión, valores, políticas
├── servicios.html      Servicios, flota, proceso de trabajo
├── cobertura.html      Mapa de rutas Ecuador – Colombia – Perú
├── contacto.html       Datos de contacto, sedes, formulario (abre WhatsApp) y mapa
├── css/
│   └── styles.css      Diseño compartido. Colores en `:root` al inicio.
├── js/
│   └── script.js       Menú móvil, animaciones, formulario de WhatsApp
├── assets/
│   ├── logos/          Logos oficiales de N.T.A.
│   │   ├── logo-nta-completo.png     Logo grande (alta resolución)
│   │   ├── logo-nta-sin-fondo.png    Logo para la web (menú y pestaña)
│   │   └── logo-nta-vectorial.svg    Logo en vector (imprenta y tamaños grandes)
│   └── fotos/          Fotos extraídas de la presentación 2026
│       ├── portada/    Foto principal del inicio
│       ├── flota/      Tractocamiones y camiones
│       ├── instalaciones/  Oficinas y patios (Ipiales, Tulcán, Quito, Huaquillas, Guayaquil)
│       └── carga/      Fotos de carga y clientes
└── documentos/
    └── presentacion-nta-2026.pdf   Company profile 2026 (descargable desde Nosotros)
```
